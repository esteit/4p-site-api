# 4Partners Site API v2

Public description of the 4Partners Site API v2 — the API of a partner storefront: catalog, cart and checkout of
customers, orders of the site, content and settings.

- API: `https://api.4partners.io/v2` — every operation is `POST` with a JSON body.
- Interactive documentation: <https://api.4partners.io/v2>.
- Documentation for language models: <https://api.4partners.io/v2/llms.txt>.

This repository is updated automatically after each release of the API:

- `bruno/` — a [Bruno](https://www.usebruno.com/) collection with a request for every operation;
- `spec/` — snapshots of the OpenAPI specification and `llms.txt` of the released version.
